01

选豆：风味从产地开始

咖啡豆是一种农产品，产地的海拔、气候和处理方式，决定了它最初的味道。先从三个产区开始，找到自己喜欢的方向。

埃塞俄比亚

耶加雪菲

花香与柑橘调明亮，酸质干净，像一杯温热的茉莉花茶。

水洗 · 浅烘
哥伦比亚

慧兰

焦糖与坚果的甜感扎实，酸甜平衡，适合每天一杯。

水洗 · 中烘
中国云南

保山小粒

红糖、可可与淡淡的果干，醇厚温润，是家门口的好豆子。

日晒 · 中深烘
02

烘焙：决定一杯咖啡的性格

同一支豆子，烘焙程度不同，喝起来判若两杯。浅烘保留更多果酸与花香，深烘则带来可可、焦糖与更厚的醇度。

浅烘 — 明亮中烘 — 平衡深烘 — 醇厚
03

研磨：粗细与新鲜

豆子磨开后，香气在十几分钟内就会大量散失，最好冲之前现磨。另外，烘焙后的第 5 到 14 天通常是风味最好的时候。

手冲建议中细研磨，颗粒大约像细砂糖。喝到苦涩就调粗一格，淡而发酸就调细一格。

04

萃取：手冲四步

水温越高，萃取越快。浅烘豆可以用 92–94 °C，深烘豆降到 88–90 °C 会更稳。

  1. 温杯湿纸用热水冲湿滤纸，去掉纸味，顺便温热分享壶。
  2. 闷蒸 30 秒注入粉重两倍的水，让咖啡粉充分排气、均匀吸水。
  3. 分段注水以画圈的方式慢慢注水，保持水位平稳，分两到三段完成。
  4. 2 分 30 秒完成总时间控制在 2:30 左右，摇匀后就可以享用了。
参数推荐备注
粉量15 g约一人份
水量225 ml粉水比 1 : 15
水温92 °C浅烘可提高到 94 °C
研磨中细类似细砂糖
时间2:30含 30 秒闷蒸

    安全

    默认只显示页面，
    不运行页面脚本。

    HTML 文件可以带脚本。HTML Atelier 默认只把页面显示出来；需要运行脚本时，要你在设置里手动开启。

    01 默认

    默认预览

    页面在沙箱框架里打开，只负责把内容显示出来。

    • 页面脚本与内联事件不运行
    • 表单提交被阻止
    • 内嵌框架被移除
    阅读和可视化编辑都在这个模式下
    02 可选

    允许页面脚本

    在设置里手动开启后，脚本运行在与应用隔离的跨源沙箱中。

    • 无法直接访问应用、仓库或本地系统
    • 页面静态引用的库内脚本、图片和字体会内联进预览
    • 此时可视化编辑、阅读位置记忆、页内链接路由和嵌入自动高度不可用
    只建议对可信文件开启
    03 可配置

    网络与本地资源

    远程图片、样式、字体和媒体默认允许加载，主预览和笔记嵌入共用这一项设置。

    • 库内样式表和 @import 会内联进预览
    • 相对路径按页面所在目录解析
    • 侧栏可以查看缺失、远程和被拦截的资源
    不想加载远程内容时可以关闭

    注意：开启页面脚本后，运行时动态创建的本地资源和跨文件模块导入不会被内联。需要完整运行脚本的页面，可以用外部浏览器打开，浏览器会照常执行页面脚本。

    常见问题

    你可能想先知道这些。

    这里没有覆盖到的情况，可以看 README 里的「编辑范围与安全」，或者在 GitHub 上提问。

    查看中文说明 在 GitHub 提问
    Q 可视化编辑会把整份文件重新格式化吗？

    不会。可视化修改只改你动过的那一段，没动过的标签、属性、注释、缩进、换行和实体写法都保持原样。要改页面结构，请切到源码模式。

    Q 页面里的 JavaScript 会执行吗？

    默认不会。预览里页面脚本和内联事件都不运行，表单提交被阻止，内嵌框架会被移除。在设置里开启「允许页面脚本」后，脚本才会运行，并且运行在与应用隔离的跨源沙箱中。这个模式下可视化编辑、阅读位置记忆等功能不可用，只建议对可信文件开启。

    Q 支持手机或平板上的 Obsidian 吗？

    不支持。HTML Atelier 仅支持 Obsidian 桌面版 1.7.2 及以上，Windows、macOS 和 Linux 都可以使用。

    Q 会和别的 HTML 插件冲突吗？

    如果另一个已启用的插件也接管 .html 或 .htm 文件，两者会在文件类型注册上冲突。请先停用那个插件，再用 HTML Atelier 打开页面。

    Q 草稿备份存在哪里？卸载前要注意什么？

    默认存放在 .obsidian/plugins/html-atelier/drafts/，包含原始 HTML 和编辑后的内容。如果同步工具会同步插件目录，这些备份也会被同步。删除插件目录前，请先保存需要保留的草稿。

    Q 怎么把 HTML 页面嵌进笔记？保存后嵌入没更新？

    在笔记里写一个 html-atelier 代码块：

    ```html-atelier
path: "页面/一杯好咖啡的诞生.html"
height: auto
anchor: brew
toolbar: false
```

    嵌入读取的是已保存文件，不会显示当前未保存的草稿。保存修改后，点嵌入里的刷新按钮重新载入。

    Q 远程图片和字体会加载吗？可以关吗？

    远程图片、样式、字体和媒体默认允许加载，可以在设置里统一关闭，主预览和笔记嵌入都会生效。库内通过 <link rel="stylesheet"> 和 CSS @import 引用的样式表会内联到预览中。

    Q 可视化编辑能改 CSS 和页面结构吗？

    不能。可视化编辑只覆盖页面文字、链接文字与地址、图片地址和替代文本。CSS、HTML 结构、表单字段值，以及 SVG 等排除元素内的文字，请用源码模式修改。开启「允许页面脚本」时，可视化编辑也不可用。
